> 修訂紀錄：v0.1 = 「社團的遊戲世界」（已被取代，見 git 歷史）；v0.2 初版 = 老宅尋寶・單人詭異版（叔公、律師、五封信、阿河與小桐，2026-11-02，已被取代，見 git 歷史）；**v0.2（新劇情，2026-11-03）= 老宅魔方・森林圖書館**：爸爸過世、祖先許問津的魔法試煉、書房地毯下的魔法陣、房子像魔方一樣重組（取代原「夜晚折疊」與五封信門檻）、提示改為「父親的筆記」、追逐者改為守衛殘影、兩個結局改寫、新增魔方重組規則（第 5 節）與森林圖書館美術風格（第 8 節）。使用者定案。

## 1. 世界觀

### 1.1 一句話
爸爸過世三年後，你獨自回到山上的老宅整理遺物，不小心踩亮了書房地毯下的魔法陣——祖先許問津留下的試煉開始了，房子像魔方一樣轉動、鎖死。你唯一的目標，是走到最深處，讓它還原、離開。

### 1.2 設定細節

| 問題 | 答案（給玩家的說法） |
|------|---------------------|
| 為什麼回老宅？ | 爸爸過世後，老宅空了三年。暑假最後一週，你決定一個人回去住幾天、整理他的東西。沒有人叫你來，也沒有人在等你。 |
| 為什麼是你？ | **不是被選中，是不小心**。你想把書房的地毯捲起來打掃，一踩上地毯下的魔法陣，它就亮了；鋼筆從陣中央升起，你下意識握住。許家只有具資質的後代，鋼筆才有反應、試煉才會啟動——你剛好是。 |
| 為什麼只有你一個人？ | 你是一個人來的。老宅在山上，沒有手機訊號；試煉一開始，房子重新排列，門打不開、窗推不動。 |
| 有期限嗎？ | **沒有**。不顯示時間、不會因為慢而失敗（規格 P3）。唯一目標是離開：出口被魔方鎖死，只有走到最深處（終點），房子才會還原。 |
| 房子怎麼了？ | 許問津把整棟老宅設計成魔法試煉。試煉一開始，房子就像魔方一樣重新排列：牆移動、樓梯翻轉、房間被拼成新結構。**每一章是一次重組，格局都不同**；章與章之間共重組五次，第五次之後通往最深處。重組規則見第 5 節。 |
| 為什麼能切換 2D / 3D？ | 鋼筆：點一下，房子被壓平成一張圖（**藏寶圖**視角，看得到整個魔方的結構與房間之間的接縫）；再點一下回到**實景**（3D）。圖上看得見機關與拼接，但只有在實景裡才能推、拿、走。 |
| 為什麼兩邊不一樣？ | 許問津把有些機關只畫在圖上（只在 2D）；有些東西是後代搬進來的，圖上沒有（只在 3D）。圖是平的，所以沒有前後。 |
| 為什麼圖裡跳得比較高？ | 「紙上的人比較輕？」——父親的筆記 |
| 詭異的來源？ | **守衛殘影**：許問津留下來看守試煉的影子。實景看不見，只有藏寶圖裡看得到模糊的人形。它們攔住闖試煉的人，**只攔不傷**；也會重複自己看過的動作——包括爸爸這些年在老宅裡翻書、踱步、撕圖的樣子。 |
| 掉進坑會怎樣？ | 「圖面一皺」，你回到最近的檢查點。沒有受傷、沒有死亡畫面。 |
| 為什麼中途不能存檔？（規格 Q4） | 試煉的每個房間自成一關：離開房間（通關）時，老宅才「記住」你做過的事。重新進房（R）= 這個房間的機關回到原樣。 |
| 提示從哪來？（規格 7.1） | **父親的筆記**：爸爸沒有資質，一輩子偷偷研究老宅，全憑推理，在各處留下片段的筆記。有些筆記一開始看起來是空白的——試煉會把它們藏起來，等你在同一處卡住時，字跡才慢慢浮現（卡關偵測）。設定「提示隨時可用」= 字一開始就顯好。 |
| 寶藏呢？ | **不是目標**。路上拿到的東西——鋼筆筆尖、「許」字火漆印章、建築剖面尺、圖釘——就是許問津留給後代的「寶藏」。 |

## 2. 角色

> 玩家稱「你」，不指定性別；暱稱於開始時輸入（存檔 `name`，過場與結局使用）。**沒有同行 NPC**，解謎途中沒有對白。

| 角色 | 出現方式 | 性格 / 功能 | 代表句 |
|------|---------|------------|-------|
| 你 | 玩家 | 高中生，爸爸的孩子；不小心啟動試煉的人，具資質 | （不說話） |
| 爸爸 | 不出場；父親的筆記（提示）、牆上的字條、沒寫完的筆記、最後一本筆記（結局 B） | **沒有資質**，一輩子偷偷研究老宅，全憑推理。筆記是觀察加猜測：片段、抽象，偶有「？」與劃掉重寫的痕跡。他在書房地毯下發現魔法陣，卻從沒成功啟動；本來打算自己先解開再告訴你，來不及 | 「我試了一輩子，從沒成功。」 |
| 許問津 | 不出場；手記 ×5、「許」字火漆印、鋼筆筆身的字 | 祖先，魔法師；把整棟老宅設計成試煉，只對有資質的後代回應。語氣簡短、像規則 | 「點一下，換個角度看。」 |
| 守衛殘影 | 只在藏寶圖裡看得到的模糊人形 | 許問津留下的守衛；攔住闖試煉的人，只攔不傷；會重複看過的動作 | （不說話） |

**殘影與追逐的詮釋**：殘影把拿著鋼筆、在試煉裡亂走的你當成「闖進來的人」，衝過來攔；在實景裡碰不到你。被碰到時，圖面一皺，你回到檢查點，什麼都沒丟（規格 N19）。手記第三頁揭曉「只攔不傷」；結局 A 它們排成一列向你低頭。

**主題**：換個角度看，就會懂——同時是玩法（切換視角、看懂魔方的拼接）、許問津刻在鋼筆上的話，以及爸爸的遺憾（他一輩子只能從圖外面推理，從沒進到圖裡）。

## 5. 魔方重組與關卡一句話劇情（22 關 + 3 隱藏房，每句 ≤ 30 字）

### 5.1 重組規則（敘事版；機制定義見規格 5.4）

老宅由 22 個「房間模組」組成，像魔方的面片。試煉在**章與章之間**（過場中）轉動模組；**關內格局固定**（確定性，不在解謎途中轉動）。

| 規則 | 玩家看到的樣子 | 藏寶圖（2D）上 | 實景（3D）裡 |
|------|--------------|---------------|-------------|
| **翻面** | 房間前後翻轉：前牆變後牆 | 幾乎不變（圖沒有前後） | 深度顛倒：原本在前面的東西跑到後面 |
| **對調** | 兩間房互換位置 | 接縫改接到新鄰居 | 門後換成另一間房 |
| **層轉** | 一整層房間繞橫軸轉：上層沉到下面、地板變牆 | 看得到整層的方塊換了位置 | 樹根從天花板垂下、樓梯倒過來 |
| **錯位接合** | 兩間房的接面錯開一格：門對上的是隔壁的牆，或高了一層 | **只在圖上看得到接縫線**（哪扇門此刻接到哪一面） | 每扇門框看起來都一樣；走錯門只會碰到牆 |

### 5.2 章節旁白與重組

| 章 | 旁白（1～2 句） | 本章的格局（由哪次重組產生） | 本章主要規則 |
|----|----------------|--------------------------|------------|
| 第一章 玄關 | 門打不開了。手裡的鋼筆，像在等你。 | 序章的初次轉動 | 錯位接合（教學：真正接通的門只在圖上看得出） |
| 第二章 書房 | 書都朝著牆。爸爸寫過：背面才是正面？ | 第一次重組（翻面）：玄關翻到背面，門的另一頭接上書庫 | 翻面（圖不變、實景前後顛倒） |
| 第三章 溫室 | 植物朝著一盞燈長。有些影子，比植物先到。 | 第二次重組（對調）：書庫和溫室對調 | 對調（出口接到對調後的鄰居） |
| 第四章 地下室 | 這裡的東西被封起來了。封住的，不只是東西。 | 第三次重組（層轉往下）：溫室那一層沉到樹根底下 | 層轉（地板與牆的方向改變） |
| 第五章 閣樓 | 三扇天窗，三種看法。爸爸只看過其中一扇。 | 第四次重組（層轉往上）：整層翻上觀星閣樓 | 錯位接合（三翼的門錯開一格） |
| 終章 草地 | 天快亮了。最深處，是一片草地。 | 第五次重組（收束）：所有模組向中心收攏 | —（還原前的最後一間） |

章末過場固定演出一次重組（逐字稿見 `cutscenes-v0.1.md`）；第五次重組在 5-5 三道光對齊時於遊戲內演出。

## 7. 文案風格指南與範例（高中版）

### 7.1 規則
- 讀者：高中。句子短，但可以更成熟：留白、暗示、不把話說滿。
- 旁白 / 字條 ≤ 40 字；一句話劇情 ≤ 30 字；提示字條另遵守規格 7.1.1（H1～H10）與 7.1.3 預算。
- 詭異來自「不對勁」：重複、慢半拍、少了一個人、房間接錯了地方；**不靠血腥、傷害、死亡**。爸爸的過世只用「過世後」帶過，不描寫過程與病痛。
- 不依賴會過時的流行語；不影射現有 IP，不套用知名恐怖作品的經典橋段（例如鏡中人、電話來電、娃娃轉頭）。
- 守衛殘影沒有惡意。任何文案都不得把殘影寫成怪物或復仇者。
- **父親的筆記的語氣**：觀察加猜測，片段、抽象；偶有「？」、劃掉重寫的痕跡；對自己說話，不對玩家下指令。**提示字條仍必須好讀、不誤導**：
  - 劃掉的部分只能是爸爸自己否定的猜測（≤ 6 字），不得是解法步驟或錯誤指引；劃掉的字不計入 H1 字數。
  - 劃線只用單條橫線、字仍可辨識；不扭曲、不殘缺。
  - 每張提示的未劃掉部分本身就是一句完整、好讀的話。
- 許問津的手記語氣：像規則、短、不帶情緒；不破題。

## 8. 美術風格：魔法師的家＝森林中的圖書館

### 8.3 材質
- 木：直紋、邊角磨圓；書架頂端消失在暗處（高聳感，但謎題 `area` 內照度照規格 9.1）。
- 書與羊皮紙：書背是同色系色塊；半浮的書以 2～4 cm 的緩慢上下浮動呈現（純裝飾，非實體；減弱動態時靜止）。
- 樹根與藤蔓：從牆縫、地板縫鑽出，屬裝飾 decor；**不得改變碰撞或遮住謎題物件**，與可互動物件明顯區分。
- 苔蘚：鋪在石階、窗台、地板邊緣。
- 魔法陣刻紋：同心圓與星形線，平時是深棕刻痕；試煉相關的時刻（序章、結局、5-5 收束）才發墨水藍光。
- 2D 藏寶圖：同一組模型的扁平色＋深棕描邊（沿用 `Painter`）；房間之外的相鄰模組以淡墨線畫出，接縫（N20）以虛線＋小墨點標出。
