## 1. 設計支柱、目標玩家、時長

### 1.1 設計支柱（可用來否決提案）

| # | 支柱 | 檢查方式 |
|---|------|----------|
| P1 | **兩種視角缺一不可**：每個謎題都必須同時用到 3D 與 2D 能力，只用一種視角必定解不開。v0.3：**規劃在 2D、行動在 3D**——展開圖、標籤、字卡只在 2D；拉桿、推、走、穿門只在 3D。v0.4：第一章的拉桿照舊在 3D 拉；**第二章起轉動在 2D 展開圖的控制盤執行**（N32），推、走、穿門、拿取仍只在 3D，所以魔方題天然需要兩個視角 | 每個謎題至少一條「只用單一模式」的反例測試（魔方範式的首次教學題豁免「只用 3D 試出來」，D2；第二章起的魔方題以「不看預覽盲轉」反例取代，D2） |
| P2 | **一章一個頓悟**：每章的核心 aha 推翻或延伸前一章建立的直覺（不是換座標） | 第 5 節表格「本章 aha」欄不得重複 |
| P3 | **以安靜推理為主**：無真實計時、無精準跳躍要求；少數段落允許驚嚇（每章 ≤ 1 次）與追逐（全遊戲 3 次，N19），**不構成失敗、不懲罰進度**：被追上只回檢查點、進度與物件位置不丟；設定「減弱緊張效果」可讓追逐自動通過、驚嚇改平靜版（9.1） | 不出現計時器；跳躍高度餘裕 ≥ 0.15（D10）|
| P4 | **物件會說話**：可互動 / 只在某視角存在 / 可蓋印 等狀態一律有形狀符號，不只靠顏色 | 第 7 節無障礙檢查表 |
| P5 | **許問津的試煉**：機制都以老宅、製圖與魔法試煉語彙命名（鋼筆、筆尖、字卡、活字、建築比例尺、拉桿、魔方儀、展開圖；顯示名見 story-bible 對照表），劇情與機制同源；主題「換個角度看，就會懂」 | 新機制命名須通過此檢查 |

### 1.2 目標玩家
- **高中（約 16～18 歲）**；喜歡解謎與輕度懸疑（Portal、Monument Valley、Inside 一類氣氛），不要求平台跳躍技術。
- 劇情：爸爸過世三年後，你獨自回山上老宅整理遺物，不小心啟動祖先許問津留下的魔法試煉；房子像魔方一樣重組、鎖死；你用鋼筆在實景與藏寶圖之間切換、在圖上改字與改大小；第一章拉動房間裡的拉桿、第二章起啟動魔方儀、在展開圖的控制盤上自己選要轉哪一組，轉動魔方，走到最深處讓它還原、離開（見 `story-bible-v0.2.md`）。
- **平台**：桌機瀏覽器（鍵盤：WASD / Space / F·Q / E / T / R，見 `input/bindings.ts`）與**手機 / 平板瀏覽器**（觸控：iOS Safari 16.4+、Android Chrome 111+，橫屏優先、直屏可玩；詳見 `mobile-controls-v0.1.md`，暫定 Q-I）；兩種輸入可同時存在。手把列為日後擴充。

### 1.3 時長估計〔推論〕
| 項目 | 估計 |
|------|------|
| 主線總時長 | 約 4～5.5 小時（50 個主線謎題，各章題均 3.5～8 分；計算見 5.2） |
| 每關 | 8～20 分鐘（Boss 18～22 分為唯一例外） |

| 隱藏房 | 3 間各 1 題，每間 10～15 分鐘（另計） |

**現況的隱含規則（設計時要當成「物理定律」）**
- R1：**機關只在它存在的視角更新**（`updatePlates` 跳過非目前模式的壓板）。目前因壓板會鎖定而無感，若加入「非鎖定壓板」就會成為可利用的規則（見 N4）。
- R2：2D 的「位置」只有 x；z 只決定 3D 裡誰擋誰（C2、C6）。玄關與書房都建立在這條直覺上，溫室會刻意推翻它（N6）。
- R3：玩家在 2D 推不動任何東西；能改變世界配置的只有 3D 推箱與互動（C5）。
- R4：可見模式是物件的固定屬性；目前沒有任何方式改變（定稿印 N5 會打破）。

**玄關謎題鏈（現況，v0.2 版）**：1-2a 書架過缺口 → 1-2b 推箱取筆尖 → 1-2c 長桌下的踏板 → 1-2d 高處的墨水閥（物歸原處回收木箱、站箱頂轉閥）→ 出口門（`content/levels/ch1/1-2-foyer.ts` 註解；`tests/puzzle/levels/1-2.test.ts`）。v0.3 的保留 / 改 / 廢見 6 節第一章。

### 5.4 魔方（v0.3 主軸；取代 v0.2 的 5.4「重組只在章間、N20 接縫」）

#### 5.4.1 概念與名詞

| 名詞 | 定義 |
|------|------|
| 魔方（cube） | 每章一個；由「格」組成。格裡是**房間**（一關 = 一間）、**裝飾房**（走廊、樓梯間，只有通道或收集物）、**實心格**（不能進入，只在展開圖上有圖案）或**空格**（滑動用） |
| 房間（面片） | 房間內部格局不變，仍是正常的 2D/3D 關卡；只有「門接到哪」隨魔方狀態改變。房間在魔方上有位置與朝向（第四、五章才會轉朝向） |
| 門位 | 每間房最多 6 個門位：N 後牆、S 前緣（拱門形，走向鏡頭穿過）、E 右端、W 左端、U 天花板梯口、D 地板梯口（U / D 只在第四、五章） |
| 通道型別 | **門**（只有人能過）、**拱門**（人與可推物都能過，5.4.6）、**章門**（只通屋框的走廊，需房間的銅鑰匙）。兩側型別不同時取較窄者 |
| 屋框 | 房子本身固定的開口，接在魔方的固定格邊上：大門（第一章，通門廊）、各章的章門走廊、天窗（光源）。屋框不隨轉動移動 |
| 接通規則 | 房間 a 的 s 門位有門、相鄰格的房間 b 在相反門位有門 → 接通；任一方沒有門 → **門後是牆**（3D 訊息「門後是牆。」，無懲罰）；門牌「間」例外（5.4.5） |
| 轉動方式（v0.4） | **第一章：拉桿**（3D 世界物件，`interactIn:'3d'`）——房間內的拉桿帶方向字，3D 按 E 拉，整個房間連人帶物滑向該方向；拉過不能拉回（要回來得改方向字或 R），2D 展開圖可看預覽。**第二章起：控制盤**（N32）——玩家在 2D 展開圖上自己選要轉哪一列 / 行（第二章）、哪一間滑進空格（第三章）、哪一層（第四章）、哪一片（第五章）。各章對照見 5.4.2 |
| 拉桿的「轉自己」原則（只限第一章） | 拉桿只推**它所在的房間**，所以玩家永遠和被轉的房間在一起，**轉動時玩家連同房間一起移動**（短過場 ≤ 1.2 秒；減弱動態改為 0.6 秒淡入淡出）。拉桿有**標籤**（方向字），寫錯字就轉錯方向（P7） |
| 魔方儀與控制盤（第二章起） | **魔方儀**是各章一個的 3D 世界物件（2-1 黃銅魔方儀、3-1 園丁羅盤、4-1 年輪根盤、5-1 觀星儀；顯示名見 story-bible 4 節），放在該章開場就能進的房間；3D 站穩按 E **啟動**（不計題，每章一次，存入章節狀態）→ 展開圖多出**轉動模式**。啟動之後，在本章任一房間的 2D、站穩時都能開轉動模式（不必回到魔方儀旁；Q-AB）。控制盤沒有方向字標籤，方向由玩家選 |
| 轉動模式（控制盤操作） | 只在 2D、站穩時可進入；進入後移動輸入暫停（`releaseAll`），**世界不暫停**（追逐中殘影照常移動，P8）。① 點列 / 行 / 層 / 切片的**標頭箭頭**（▲▼◀▶ 或 ↻↺）選一組與方向 → 展開圖顯示預覽（半透明結果、虛線箭頭），不執行；② 按「確認」才轉（短過場 ≤ 1.2 秒，減弱動態 0.6 秒）；③「回退」撤銷上一步；④「離開」回到一般展開圖。玩家所在的房間若在被轉的那一組裡，就連同玩家一起移動；不在就不動 |
| 步數預算（墨量） | 控制盤每轉一次用 1 滴墨；**每次穿門進入一間房時，墨量補滿到該房的預算**（`turnBudget`，5.4.9），R 回到本次進房時（墨也回到進房時的滿額）。房間的「目前謎題」是 P4 題時，用 P4 題的預算（較緊）；其餘用房間基礎預算。預算一律由 BFS 最短解推導：**上限 = 最短解 + 寬裕量**（教學題 +3、一般題 +2、P4 題 +1、Boss +1），且必須小於「被刻意排除的較長策略」的步數（例：3-3b 不縮小要 5 步、縮小 3 步、預算 4）。墨用完 → 轉不動（「墨乾了。」），回退仍可用 |
| 回退一步 | 轉動模式的「回退」撤銷**本段**最後一次轉動、**退回 1 滴墨（不耗步數）**。「本段」= 上次穿門 / 拱門跨房 / 取得旗標、道具、字卡之後的轉動；這些事件一發生就清空回退堆疊。理由：R 本來就免費且回滿墨，回退只是 R 的細粒度版本，能到的（魔方, 旗標, 剩餘墨）組合與不回退時完全相同（5.4.8），收費只會懲罰誤觸、不增加防暴力效果；清空規則保證回退不能「拿了旗標再退回去」。回退的反向轉動照樣檢查轉不動（門口有東西就退不回去，說明原因）。第一章的拉桿沒有回退（拉過不能拉回，R 還原） |
| 鎖定列 / 行 | 控制盤上某些列 / 行 / 層 / 切片的標頭畫著**鎖扣**（形狀符號，不只靠顏色），轉不動（「這一排鎖著。」）；解開條件是某題的 `doneFlag` 或能力（鎖扣旁的圖示指向解鎖的房間）。用途只有兩個：教學分段（一次只開一種轉法）與壓低可達狀態數（5.4.9）。驗證器檢查每個鎖扣都可在不卡死的前提下解開 |
| 卡榫（P3，第三章起） | 巨物（放大的花盆、伸出房間的樹根、縮影裡的齒輪）伸進魔方軌道 → 牽涉到這間房的轉動一律轉不動；展開圖在該軌道畫卡榫記號。縮小 / 移走才鬆開。第三章之前不出現 |
| 展開圖 | 只在 **2D 藏寶圖**看得到：整個魔方的格、房間名、門位與接通狀態（接通 = 實線 + 墨點；門後是牆 = 斷線 + ×；拱門 = 雙線；P4 形狀區分）。第一章站在拉桿旁（2D）時顯示該拉桿的轉動**預覽**（半透明），不執行；第二章起在轉動模式中預覽玩家選的轉動，並顯示剩餘墨量（墨點）、鎖扣、卡榫記號、回退是否可用。3D 只看當前房間 |
| 轉不動 | 第一章：目標格不是空格、門口或拱門上有東西 / 玩家跨在房間邊界。第二章起另加：選的那一組被鎖住、巨物伸進軌道（P3 卡榫）、墨用完。一律不動並說明原因（「門口有東西卡著。」「這一排鎖著。」「軌道卡住了。」「墨乾了。」） |
| 章間轉動（敘事） | 第一～四章的章門打開後，整棟房子在章末過場轉一次，把下一章的魔方接到章門外；第五次是 5-5c 的收束（遊戲內演出，露出中心 6-1）。共五次 = 手記「此宅會轉五次」；序章的初次轉動是試煉啟動，不計入。**只在過場演出，不是玩法規則**；玩法上只有章內轉動 |
| 鏡頭 | 不旋轉：3D 鏡頭永遠在房間的本地座標；房間朝向改變只反映在展開圖與門的接法（不做 Fez 式旋轉） |

#### 5.4.4 轉動運算（純函式、離散、可重現）
- `slide(cube, room, dir)`：鄰格為空才移動。`rowTurn(cube, row, ±1)`、`colTurn(cube, col)`：循環平移 / 對調。`layerTurn(cube, layer, cw|ccw)`：位置繞層中心轉 90°，房間朝向 +1 / −1。`sliceTurn(cube, axis, index, cw|ccw)`：三軸切片，中心格不動。
- 門的實際朝向 = 房間本地門位依朝向旋轉（U / D 不受層轉影響）。
- 每次轉動是一個離散動作，不經過中間狀態；同樣的動作序列永遠得到同樣的魔方狀態。
- v0.4：上述運算統一由 `applyTurn(def, state, turn)` 分派（`turn` = `{ group, dir }`；第一章拉桿也轉成 `slide` 的 turn），回傳新狀態或轉不動的原因；回退 = 對上一步套用反向 turn（列轉 ±1 互為反向、行轉對調自為反向、滑動反向回原格、層 / 切片 cw ↔ ccw）。

#### 5.4.5 方向字與門牌（寫 × 轉）
- 拉桿的方向字決定轉向：拉桿「上 / 下 / 左 / 右」。用詞卡蓋掉原字即改變轉向（P7）；取下卡片原字恢復。**只在第一章**：第二章起的控制盤沒有方向字標籤，方向由玩家選，P7 改以門牌出題。
- 門牌：門的標籤預設「門」。貼部件卡「日」→「間」：**這扇門對面就算沒有門也接得上**（在鄰房那面牆上開出門洞；P7 的「多接一個房間」）；v0.4 補充：開出的門洞與這一側同型（這側是拱門就開出拱門形的洞，箱子推得過去）。其他門牌字一律無效（字顫動、墨色變淡，卡片退回）。

#### 5.4.6 跨房物件（拱門）
- 兩側都是拱門時，可推物能被推過房間邊界：中心點越過邊界的那一刻，物件移到鄰房，出現在對面拱門內側（該處被佔時推不過去）；玩家跟著走就換房。
- 物件「屬於」它所在的房間：房間轉動時，裡面的物件跟著走（P2 帶物轉運的基礎）。道具（小物）屬於玩家的章節道具欄，跟著玩家走（P13）。
- 只有拱門讓物件跨房；門與章門只讓人過。

#### 5.4.8 公平與可驗證
- **退路**：T 物歸原處（本房）；R 重進房間（需確認）＝整個章節狀態（魔方排列、各房物件、字卡、道具、旗標）回到**本次進房時**，所以魔方狀態可還原；暫停選單「章節重來」（需確認）回到本章開始。**不提供「只還原排列、保留道具」的全域復位**：它等於一條萬用捷徑（例：1-3b 可直接被跳過）。改由驗證器保證不卡死。
- **驗證器**（`devtools/validateCube`，廣度優先搜尋）：抽象章節模型 = 魔方狀態 × 玩家所在房 × 機關方向字 × 字卡擺放 × 關鍵旗標（房內謎題以「前置 → 旗標」抽象，房內物理另由每關通關腳本與捷徑掃描驗證）。檢查：① 有解；② **任一可達狀態都能到終點**（不卡死）；③ 最短解的轉動步數與 P4 墨量上限（上限 = 最短解 + 0～2，否則報「步數上限不合理」）；④ 拿掉任一必要步驟（不寫字、不推箱、不拉某機關）就無解（捷徑檢查）；⑤ 並行入口數 ≥ 2（第一章除外）。
- **v0.4 擴充（控制盤章節，供 M-Dial 實作；第一章模型照舊）**：抽象狀態另加 **剩餘墨量**（穿門時補滿到目標房的預算）、**已啟動的魔方儀**、**已解開的鎖扣**、**卡榫狀態**（巨物的尺度檔）；轉動邊 = 控制盤上未鎖、未卡、有墨的每一組 × 方向。回退**不另建模**：回退能到的（魔方, 旗標, 剩餘墨）組合，不回退也能以「從本段起點照原路再轉一次」到達（旗標一變就清空回退堆疊，所以本段內旗標不變），回退只新增指向已可達狀態的邊、不新增狀態；卡死檢查不計回退邊（保守：不靠回退也不卡死，有回退更不會）。新增檢查：
  - ⑥ **步數上限檢查**：每個房間預算 = 該房各題（在該房開始的題）最短解 + 寬裕量的最大值（5.4.1）；P4 題預算 = 最短 + 1，且必須 < 被排除策略的最短步數（例：不縮小、不改門牌）；另檢查**預算繞過**：允許中途穿門補墨的模型裡，P4 題的 `doneFlag` 若能以「每次進房都少於 P4 預算」的方式達成，報「預算可被換房繞過」。
  - ⑦ **多解列舉**（D16）：對每題，在步數上限內列舉所有可行轉動序列（狀態不重複；超過 10⁴ 條時改為依深度分層取樣 10⁴ 條），回報**解法數量**（序列數、本質不同的轉動多重集合數）、**最短解與次短解**的步數；非教學題本質不同的解 < 2 → 報「解被限制收斂成唯一」；最短解 = 預算 → 報「沒有寬裕量」。

  - ⑨ **鎖定列解鎖可達性**：每個鎖扣的解鎖條件在「該鎖未開」的子模型中可達；不存在兩個鎖互相等待（鎖的依賴圖無環）；解鎖前的可轉組合足以完成解鎖所需的題。
  - ⑩ **控制盤入口可達性**：魔方儀所在房從章門入口不經任何轉動即可走到（第二章起每章必須成立），且啟動前沒有任何謎題需要轉動。

## 7. 提示系統與無障礙

### 7.1 提示：場景裡的字條（適量、抽象、不破題）〔來源：Room Escape Artist——提示是把玩家推回邏輯路徑，不是給答案；同一提示被 ≥50% 隊伍需要即該修謎題〕

使用者決定：**不設會跟玩家說話的提示角色**（原 AI 小助手「小格」整個移除），提示只用場景裡的字條——延續現有 `note` 物件（靠近、站穩、按 E 閱讀，C9、C14）。劇情上是**父親的筆記**：爸爸一輩子研究老宅、留在各處的片段推理（只有你一人，沒有同行角色）。提示要**適量、抽象、不破題**，動作永遠由玩家自己組出來。

| 級 | 形式 | 給什麼 | 字數上限（署名不計） | 出現方式 |
|----|------|--------|---------------------|---------|
| L1 意象 | 一開始就貼在謎題附近的字條 | 方向感、情緒或意象；不碰機制 | 24 字 | 進入關卡即可讀 |
| L2 觀察問題 | 原本**空白**的字條，時間到才浮現字跡 | 一個觀察問題 | 30 字 | 進入謎題 4 分鐘，或卡關偵測提前；浮現時字條**邊角微微發亮**，不彈窗、不對話、不打斷 |
| L3 缺口的形狀 | 同上 | 只指出「還缺什麼樣的東西」，不指出怎麼補 | 36 字 | 進入謎題 8 分鐘，或卡關偵測提前 |
| L4 解答手稿（安全閥，暫定，待確認 Q-D） | **不在場景裡**：暫停選單「許問津的解答手稿」頁 | 逐步解法 | 不限 | 見 7.1.2；預設關閉，需主動開啟並確認警語 |

- **節奏**（沿用 Q3「計時解鎖」，改在場景內呈現）：L1 不計時；L2、L3 的空白字條一開始就貼好，時間到才浮現字跡。設定「提示：計時 / 隨時 / 關閉」照舊——「隨時」= 空白字條一開始就有字；「關閉」= L2、L3 字條不放（L1 仍在，因為它是場景的一部分）。
- **敘事**：試煉會先把爸爸的部分筆記藏成空白，「給卡住的人一點時間」；你在同一處反覆嘗試時，字跡浮現得比較快（卡關偵測）。
- **卡關偵測**〔推論〕：以謎題進度旗標為單位；同一謎題內 T 歸位 ≥ 3 次、或切換 ≥ 12 次無新旗標、或掉落 ≥ 3 次 → 下一張空白字條提前顯字。只作用於 L2、L3，不會打開 L4。
- **H 鍵**：只用來**重看本關已出現過的字條**（唯讀清單，不會叫出新提示）。
- **資料格式**：每題 0～3 張提示字條，依 7.1.3 預算；每張是關卡裡的 `note` 物件，帶 `hint: { puzzle, level, truthRef }`；每題另有 `keyObjects`（H4 檢查用）、`solutionKey`（L4）。詳見 `architecture-v0.2.md` 4.10。
- C9「看得見，卻碰不到。換個角度試試。」保留為即時規則回饋（系統訊息，無說話者），不算提示、不受量表限制。
- 範例（1-1～1-3、2-1 全部謎題）與破題檢查見 story-bible 7.3；魔方 / 寫 / 量題的抽象示例見 7.1.4。
- v0.3：魔方題的 `ahaTerms` 預設包含「轉」「魔方」「排列」「滑」「對齊」「跟著」「一起」與該題機關的方向字（v0.4：第二章起另含「整列」「整行」「整層」「切片」「墨」「鎖」；用詞組而不用單字「行」「片」，避免誤判一般用字）；寫題包含「字」「寫」「改」與答案字；量題包含「大」「小」「縮」「放大」「重」。

#### 7.1.1 字條撰寫量表（可檢查規則）

| # | 規則 | 檢查方式 |
|---|------|---------|
| H1 | 字數：L1 ≤ 24、L2 ≤ 30、L3 ≤ 36 字（署名與劃掉的字不計） | 關卡驗證器（自動） |
| H2 | 禁用句型：「把…」「先…再…」「去…」「到…」等祈使句開頭；「推到 / 推去 / 推過 / 站上 / 走到 / 跳上 / 切到」 | 驗證器：開頭詞與動詞清單 |

#### 7.1.2 安全閥評估（暫定，待確認 Q-D）

| 方案 | 優點 | 缺點 | 評估 |
|------|------|------|------|
| (a) 只有字條（適量、抽象） | 最好玩、最安靜、最一致 | 字條變少又更抽象，青少年卡太久容易直接放棄；一題卡死 = 整章卡死（線性） | 單獨不夠 |
| (b) 暫停選單「許問津的解答手稿」頁 + 擴充題可「跳過此題」 | 保證不會永久卡關；不在場景裡、沒有角色口吻，不破壞氣氛 | 太容易打開就會被濫用 | **採用**，預設關、要主動開、要等、要確認 |
| (c) 卡關偵測讓空白字條提前顯字（沿用） | 卡住的人更快拿到抽象字條 | 只加速 L2、L3 | **採用**，不得打開 L4 |

**建議（暫定值）**：(a)+(b)+(c)。因為字條變少、更抽象，**L4 的重要性上升**，但仍維持預設關閉、需主動開啟：
- 解答手稿頁在暫停選單，按謎題列出；某題要在**進入謎題 10 分鐘後**才可打開（卡關偵測可縮到 6 分鐘，因為很多題沒有 L2 / L3，不能用「L3 出現後」當條件）；打開前顯示警語（手稿封面上許問津的字：「看了，就不算試煉了。」）並需再按一次確認。
- 設定「解答模式」（預設關，開啟時同樣顯示警語）：開啟後解答手稿頁不必等待。
- 「跳過此題」只在解答手稿頁裡、只限擴充題（核心題會斷教學鏈）。
- 統計：某題 ≥ 20% 試玩者打開解答手稿 → 該題或其字條要重做（比 D7 的 50% 更嚴，因為等同看答案）。

#### 7.1.3 字條預算（適量）

| 謎題難度 | L1 | L2 | L3 |
|---------|----|----|----|
| < 3 | 0～1（可不放） | 0 | 0 |
| 3～4.5 | 1 | 0（標「易卡關」才放） | 0 |
| 5～6.5 | 1 | 1 | 0 |
| ≥ 7 | 1 | 1 | 1（或 G1 資料顯示需要時才放，見下） |

- **每關提示字條總數 ≤ 該關謎題數 + 1**；超出時從難度最低的謎題刪起。
- 難度 < 7 的謎題要加 L3，必須有 G1 試玩數據（該題 L2 出現後仍有 ≥ 50% 試玩者卡超過 4 分鐘）。
- **不擠在一起**：同一個 2D 畫面寬度內（約 16 單位）可見的字條（提示 + 劇情）≤ 3 張，兩張間距 ≥ 3 單位；每關字條總數（提示 + 劇情）≤ 謎題數 + 3。
- 隱藏房（難度 7～9）同樣適用此表。

- **測試策略**：關卡驗證器自動檢查 H1～H4、H10 的 `ahaTerms` 字串比對、預算表（每題張數符合難度、每關總數上限）、字條位置（每張提示字條位於所屬謎題的 `area` 內、兩模式都站得到、間距與每畫面數量上限）；H5～H10 的語意部分人工審稿；H8 抽象度併入 G1 試玩決策點。

#### 7.1.4 魔方 / 寫 / 量題的字條示例（抽象示例，已依 H1～H10 自查）

| 類型 | 級 | 示例 | 為什麼不破題 |
|------|----|------|------------|
| 魔方 | L1 | 這扇門後面，以前不是牆。 | 只給「門後曾經不同」的意象，不提轉、排列、機關 |
| 魔方 | L1 | 這房子好像記得另一種樣子。 | 只給情緒；不指出哪一間、怎麼變 |
| 魔方 | L2 | 門沒有變。變的，是門外的什麼？ | 一個觀察問題，把目光引到鄰房，不說要動哪一間 |
| 魔方 | L2 | 圖上，哪裡一直空著？ | 只問觀察，不說要滑進去（不含「滑」「轉」） |
| 魔方 | L3 | 缺的不是鑰匙，是肯讓開的鄰居。 | 指出缺口的形狀（需要有房間讓位），不說是哪間、往哪裡 |
| 魔方 | L3 | 要接上的那一面，現在朝著別處。 | 指出缺口（朝向不對），不說轉幾次、轉哪一層 |
| 寫 | L1 | 牆上的字，比牆還固執。 | 意象：字有力量；不提哪個字、改成什麼 |
| 寫 | L2 | 這個字，少了什麼才不像它自己？ | 觀察問題，指向部件，不給部件名 |
| 量 | L1 | 小時候，你覺得這盆花好大。 | 意象：大小是相對的；不提尺度卡 |
| 量 | L2 | 卡住它的，是它的哪一部分？ | 觀察問題，引到「尺寸」以外也可能的原因，不說縮小 |

數字、方位精確詞、按鍵名一律不出現（H3）；不點名拉桿、魔方儀、控制盤、字卡匣等關鍵物件（H4，依各題 `keyObjects`）；L1～L3 依 7.1.3 預算放置。

### 7.2 無障礙

### 9.1 氛圍與緊張感（全遊戲）
