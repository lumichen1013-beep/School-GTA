# 學校GTA (School GTA 3D)

經典 3D 第三人稱視角（Third-Person Perspective, 3D TPP）校園開放世界動作沙盒遊戲。  
以台灣國中校園生活為舞台，充滿黑色幽默、校園生活彩蛋與立體探索機制！

---

## 🎮 遊戲特色

- **經典 3D 第三人稱視角**：平滑相機跟隨與 360 度自由視角，具備障礙物防穿牆射線檢測。
- **立體校園地圖**：
  - 敬業樓與樂群樓（1F ~ 3F 教室、前後門、12 組課桌椅教材、樓梯間與雙大樓空中走廊天橋）。
  - 全校升旗司令台、標準橢圓操場、籃球場（三分球蓄力投籃小遊戲）。
  - 天天合作社（熱食補血部：排骨便當、雞排、珍奶、茶葉蛋）。
  - 天天國中 25m 標準游泳館（水面浮力、划手打水動畫、50m 水上競速挑戰賽）。
  - 西北自然生態探索園區（可採摘野生紅仙菇與紫斑毒蕈、食人刺藤怪物、1200 HP 變異食人花王 Boss）。
  - 校外大街（雙黃線瀝青公路、斑馬線、持刀校外強盜追殺警戒區）。
- **載具系統**：火柴人單車，可自由騎乘、按 H 鳴鈴、高速衝撞擊飛。
- **武器與成就系統**：
  - 🥊 徒手拳擊 (25 ATK)
  - 🏏 普通木質棒球棍 (55 ATK) — 擊倒 20 名普通同學解鎖
  - ⚡ 黃金雷霆棒球棍 (120 ATK) — 擊倒生教組長、校犬與 5 名單車同學解鎖
- **訓導處記過處分系統**：
  - 操行良好 ➔ 警告 1 次 ➔ 記小過 1 次 ➔ 記小過 2 次 ➔ 記大過 1 次 ➔ 記大過 2 次 (留校察看)。
- **手機雙手觸控操作**：
  - 左側虛擬移動搖桿、右側四大動作大按鍵（攻擊、跳躍、衝刺、互動），右半部滑動旋轉視角。

---

## 🛠️ 技術架構

- **核心語言**：TypeScript (TS)
- **3D 引擎**：Three.js
- **打包工具**：Vite
- **音效系統**：Web Audio API (動態程序化音效與背景音樂合成)

---

## 🚀 本機運行指南

1. **安裝依賴套件**：
   ```bash
   npm install
   ```

2. **啟動本機開發伺服器**：
   ```bash
   npm run dev
   ```
   瀏覽器開啟：`http://localhost:3000/`

3. **建置生產版本**：
   ```bash
   npm run build
   ```
   建置產物將輸出於 `dist/` 資料夾，可直接部署至 Cloudflare Pages、Vercel 或 GitHub Pages。
