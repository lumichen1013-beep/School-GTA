# 學校GTA (School GTA 3D)

經典 3D 第三人稱視角（Third-Person Perspective, 3D TPP）校園開放世界動作沙盒遊戲。  
以台灣國中校園生活為舞台，充滿黑色幽默、校園生活彩蛋與立體探索機制！

---

## 🎮 遊戲特色

遊戲包含兩個世界，開始畫面以世界卡片選擇進入，遊戲中於大地圖（J）【地圖】分頁的「切換世界」按鈕隨時切換。

### 🏫 第一世界【天天國中】校園開放世界
- **經典 3D 第三人稱視角**：平滑相機跟隨與 360 度自由視角，具備障礙物防穿牆射線檢測。
- **立體校園地圖**：
  - 敬業樓與樂群樓（1F ~ 3F 教室、前後門、12 組課桌椅教材、樓梯間與雙大樓空中走廊天橋）。
  - 全校升旗司令台、標準橢圓操場（200m 逆時針跑道競速，對手是平時在跑道慢跑的田徑隊阿凱）、籃球場（三分球蓄力投籃小遊戲，另有兩名同學在東南籃框鬥牛）。
  - 天天合作社（8 種補給：急救繃帶、葡萄糖、特訓乾糧、運動水、大補丸、牛排便當、雞排、珍奶）。
  - 天天國中 25m 標準游泳館（水面浮力、划手打水動畫、50m 水上競速，對手是在池畔熱身的游泳隊小魚）。
  - 演藝大樓 4F 羽球場（與大如老師羽球對決，先得 5 分者勝，老師回擊率 70%）。
  - 西北自然生態探索園區（8 株效果隨機的野生奇異菇、許願池、食人刺藤與毒甲蟲、1200 HP 變異食人花王 Boss）。
  - 校外大街（雙黃線瀝青公路、斑馬線、持刀校外強盜追殺警戒區）。
- **載具系統**：火柴人單車，可自由騎乘、按 H 鳴鈴、高速衝撞擊飛；可搶奪單車騎士的車，騎士復活後會走回原處把愛車牽回。
- **武器與成就系統**：
  - 🥊 徒手拳擊 (25 ATK)
  - 🏏 普通木質棒球棍 (35 ATK) — 擊倒 5 名普通同學解鎖
  - ⚡ 黃金雷霆棒球棍 (68 ATK) — 擊倒生教組長、校犬與 5 名單車同學解鎖
  - 🏸🏸 雙燕羽刃 (25 ATK × 7 連擊，雙羽球拍) — 4F 羽球賽擊敗大如老師解鎖，只限校園
- **身法技能**：向閃身步老師學習【閃身步】(NT$1000，CD 1 秒，被攻擊時有 20% 機率自動施放) 與【狗熊哆嗦毛】(NT$2000，CD 1 秒，僅手動施放)，按 Q 閃避攻擊。
- **訓導處記過處分系統**：
  - 操行良好 ➔ 警告 1 次 ➔ 記小過 1 次 ➔ 記小過 2 次 ➔ 記大過 1 次 ➔ 記大過 2 次 (留校察看)。
  - 留校察看時主任教官會傳送到玩家所在樓層附近追捕，主任教官與生教組長皆進入暴怒 (追捕速度 +15%)。
- **校園執法者**：主任教官 (420 HP，25% 格擋反擊，招牌技「擒拿摔」) 與生教組長 (350 HP，20% 閃身步，招牌技「戒尺連打」)，一般攻擊只會踉蹌，僅連招終結技可擊飛；兩人同時貼身纏鬥時輪流出手。
- **圍攻同時最多兩人出手**：任意人數可圍住玩家，但同時最多 2 人實際出招，其餘在約 2.75m 外圈擺架式環繞等待、輪流換手，偶爾有人做樣子揮空 (騎車中的單車糾察與玩家騎車時不適用)。
- **動態天氣與程序化 BGM**：晴、雨、雷雨、霧、黃昏五種天氣（HUD 天氣按鈕切換）；BGM 依是否被追捕在校園漫步與通緝追逐間即時切換（大地圖【地圖】分頁的音樂按鈕開關）。

### ⛓️ 第二世界【第七特訓院】潛入越獄
- **MGS 式潛入關卡**：A 區監區 ➔ B 區訓練場 ➔ C 區決戰區三區全幅地圖，依序取得門禁卡 A（中央警衛室）、門禁卡 B（東側器材庫）開啟兩道管制閘門，擊破鐵面總教官取得萬能鑰匙卡後衝出南大門。
- **潛行與暗殺**：按住滑鼠右鍵（或手機搖桿推桿 ≤ 90%）靜音潛行，從背後或 18 處草堆藏匿點發動暗殺，一擊永久擊昏守衛並領取全額賞金。
- **潛行優先難度**：守衛血量厚、攻擊力高、警戒時出手更快；正面一般攻擊傷害 ×0.6 且賞金減半，打鬥聲響會引來 20m 內的守衛察看；資深與重裝守衛受擊有 30% 機率狗熊哆嗦毛閃避；特訓小賣部物價為校園 2 倍。
- **全域警戒狀態機**：ALERT ➔ EVASION（搜索 5 秒）➔ CAUTION（戒備 4 秒）➔ NORMAL，搭配中央探照燈與 MGS 風格雷達。
- **鐵面總教官 Boss**：500 HP，受擊時有機率閃身步閃避（平時 50%、硬直中 30%），可正面硬打，或誘使其衝撞撞柱硬直後暗殺，每次 100 傷害共需 5 次。
- **存檔點與評級**：取得鑰匙卡、開啟閘門時自動更新重生點；通關依時間、警戒次數與正面擊倒人數評定 幽靈 / S / A / B 級（結算顯示暗殺 / 正面比例），可重新挑戰或回主畫面。

### 🎮 操作方式
- **電腦**：WASD 移動、滑鼠視角、Shift 衝刺、Space 跳躍、右鍵潛行、左鍵 / F 攻擊與暗殺、E 互動、滾輪切換武器（或大地圖【裝備】）、Q 技能、J 大地圖（分頁頁籤位於標題列右側：【地圖】含學生證狀態卡、下一步目標、興趣點、天氣 / 音樂 / 切換世界按鈕與可折疊操作說明；【裝備】點選武器看詳情（估算秒傷、連段表、解鎖進度）再裝備，並列出身法技能；【任務】戰績與任務清單）。
- **手機雙手觸控**：左下虛擬移動搖桿；右下四顆動作按鈕（打、跳、跑、動）；點技能卡施放閃身步，換武器請開大地圖【裝備】；其餘畫面滑動旋轉視角。特訓院中搖桿推桿半徑 90% 內為潛行。

## 🛠️ 技術架構

- **核心語言**：TypeScript (TS)
- **3D 引擎**：Three.js
- **打包工具**：Vite
- **碰撞系統**：自製 AABB 碰撞盒 + 2D 均勻網格索引 (未使用外部物理引擎)
- **音效系統**：Web Audio API (動態程序化音效與背景音樂合成)
- **資源**：場景與角色全部程序化建模，無外部模型或音訊檔；支援 PWA 安裝

## 🚀 本機運行指南

1. **安裝依賴套件**：
   ```bash
   npm install
   ```

2. **啟動本機開發伺服器**：
   ```bash
   npm run dev
   ```
   瀏覽器開啟：`http://localhost:3000/`

3. **建置生產版本**：
   ```bash
   npm run build
   ```
   建置產物將輸出於 `dist/` 資料夾，可直接部署至 Cloudflare Pages、Vercel 或 GitHub Pages。
